네이버애널리틱스 (https://analytics.naver.com) 서비스를 정상적으로 이용하기 위해서는 분석을 원하는 사이트에 네이버애널리틱스스크립트(JavaScript)가 설치되어야 합니다.<br>
본 매뉴얼은 네이버애널리틱스 스크립트를 사이트에 설치하는 방법을 안내드립니다.

> ##### TIP
> 기존에 네이버광고집행을 위해 '네이버 광고 전환 스크립트'를 설치하셨더라도, 네이버애널리틱스를 이용하기 위해서는 추가로 스크립트를 설치하셔야 합니다. 
{: .block-tip }

### 1. 설치과정 개요
 - (STEP 1) 네이버 애널리틱스서비스에 사이트 등록하고 스크립트 복사하기
 - (STEP 2) 복사한 스크립트를 사이트의 소스코드에 입력하기
 - (STEP 3) 소스코드가 잘 입력되어 로그가 잘 발생하고 있는지 확인하기

### 2. 독립몰 설치과정 상세
독립몰은 사이트 주인이, 사이트의 모든 소스코드를 수정할 수 있는 사이트유형입니다. <br>
이 경우는, 네이버애널리틱스에서 제공하는 스크립트를 사이트의 가장 아래 쪽(보통 회사 정보들이 있는 푸터(footer))에 스크립트를 삽입하는 것을 추천드립니다.

#### 2.1. (STEP 1) 네이버애널리틱스 서비스에 사이트를 등록하고 스크립트 복사하기
 - 네이버애널리틱스(https://analytics.naver.com/) 사이트에 접속하고, 네이버ID 로 로그인을 합니다.
 - 사이트 및 권한 관리 (https://analytics.naver.com/management/mysites.html) 로 들어갑니다.
 - 우측 상단에 '사이트등록'버튼을 클릭하고, 사이트명, 사이트URL 을 입력하고, 우측 하단에 '등록'버튼을 클릭합니다.
 - '등록버튼'클릭 뒤 나오는 '사이트정보' 페이지에서 입력한 정보 및 '발급ID'를 확인하고, 우측 하단에 '스크립트복사'버튼을 클릭합니다 
 - 메모장 등에 '발급ID' 및 복사한 스크립트를 붙여두고, 저장합니다. 

#### 2.2. (STEP 2) 복사한 스크립트를 사이트의 소스코드에 입력하기
 - 사이트의 HTML 구문 중 제일 끝 부분인 </body> 의 바로 위에 스크립트를 설치합니다
 - 페이지 파일들 중, 모든 페이지에 공통으로 노출되면서, 제일 아래에 위치하는 파일을 찾습니다. (보통 사이트 푸터(footer)파일들이 모든 페이지에 공통으로 노출되면서, 화면상 제일 아래에 위치하는 화면을 구성하는 파일인 경우가 많습니다.)
 - 해당 파일의 아래 부분 (</body> 태그 바로 위 지점)에, 네이버애널리틱스 서비스에서 복사한 '스크립트'를 붙여 넣고, 저장 혹은 업로드

#### 2.3. (STEP 3) 소스코드가 잘 입력되어 로그가 잘 발생하고 있는지를 확인하기
 - 로그 발생 여부를 가장 쉽게 확인할 수 있는 방법은 네이버에서 공식적으로 제공하는 Chrome Extension인 '네이버 전환 스크립트 어시스턴트'를 이용하는 것입니다.
 - 네이버 전환 스크립트 어시스턴트 가이드(https://naver.github.io/conversion-tracking/pages/06_script_assistant_guide/) 중 1.2. 어시스턴트 설치방법(https://naver.github.io/conversion-tracking/pages/06_script_assistant_guide/#12-어시스턴트-설치-방법) 을 참고하여 '네이버 전환 스크립트 어시스턴트'를 설치합니다.
 - 1.4. 어시스턴트 사용방법 예시 (https://naver.github.io/conversion-tracking/pages/06_script_assistant_guide/#14-어시스턴트-사용방법-예시) 의 (STEP 2) 까지 참고하여, Chrome Extension 앱을 실행합니다
 - '네이버애널리틱스 스크립트가 설치된 내 사이트'에 들어가면, 정상적인 경우, '발급ID'에 해당되는 '사이트 ID' 가 보이고, 페이지뷰(PV)로그가 발생하는 것을 확인할 수 있습니다. 만약 발생한 로그가 없거나 혹은 앱에 보이는 '사이트 ID'가 '발급ID'와 다르다면 설치에 문제가 있는 것이므로, 사이트에 설치가 정상적으로 된 것인지 확인해주시기 바랍니다.

> ##### TIP
> 기존에 네이버광고집행을 위해 '네이버 광고 전환 스크립트'를 설치하신 경우, 사이트의 페이지에 들어가시면 '네이버 광고 전환 스크립트' 사이트ID(s_OOOO)형태의 페이지뷰(PV)로그가 1개 발생하고, 또한 '네이버 애널리틱스'용 사이트 ID(광고 전환용 사이트ID와 다름)에 의한 페이지뷰(PV)로그가 1개 또 발생하여 총 2개 발생하는 것이 정상입니다 
{: .block-tip }

### 3. 임대몰 설치과정 상세
임대몰은 사이트를 구성하는 대부분의 소스코드는 호스팅업체(예: 카페24, 고도몰, 메이크샵 등)가 제공하고, 스킨 및 일부기능만 수정할 수 있도록 되어 있는 사이트 유형입니다.
이 경우는,네이버애널리틱스에서 제공하는 스크립트를 사이트의 가장 아래 쪽에 설치하기 위해, 스킨에서 푸터(footer)에 해당되는 부분을 찾아, 스크립트를 삽입하고 저장하는 방법을 추천드립니다.

#### 3.1. (STEP 1) 네이버애널리틱스 서비스에 사이트를 등록하고 스크립트 복사하기
 - 위 2.1. (STEP 1) 네이버애널리틱스 서비스에 사이트를 등록하고 스크립트 복사하기 방법과 동일합니다. 

#### 3.2. (STEP 2) 복사한 스크립트를 사이트의 스킨의 소스코드에 입력하기
 - 임대몰 스킨(디자인) 수정할 수 있는 메뉴로 이동합니다. (예: 카페24 - 디자인(PC/모바일) -> 디자인 대시보드 -> '디자인편집' 버튼 클릭)
 - 스킨(디자인) 화면들 중, 화면 하단 푸터(footer)에 해당되는 파일을 찾습니다 (예: 카페24 - 디자인편집 화면에서 '푸터' 를 찾거나 혹은 화면들을 모아놓은 메뉴에서 '레이아웃 > 기본  레이아웃 > 레이아웃(하단 회사정보)(footer.html)'을 찾음 )
 - 푸터(footer)파일 제일 아래 부분 근처에 (STEP 1)에서 복사하는 스크립트를 삽입합니다. 

#### 3.3. (STEP 3) 소스코드가 잘 입력되어 로그가 잘 발생하고 있는지를 확인하기
 - 위 2.3. (STEP 3) 소스코드가 잘 입력되어 로그가 잘 발생하고 있는지를 확인하기 방법과 동일한 방법으로 확인합니다
